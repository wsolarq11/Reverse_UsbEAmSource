## G3 逻辑等价

关键实证（asm VA → Go，全部字符串经 rip 算术 `lea_addr+7+disp` 修正后解码）：

- 超时哨兵：`errScreenshotDXGICaptureFrameTimeout = errors.New("DXGI 捕获帧超时")`
  （20B，str @0x140c5d8db，iface @0x141bc3d90）。
- 缓存常量：Reconcile 过期阈值立即数 `0x45d964b800` = 300e9 ns = **5 分钟**；
  保留上限 **8 项**（asm 常量 8）。
- `screenshotDXGIOutputCaptureCacheKey`（0x140979820）：`"%d:%d:%s:%t:%d:%d:%d:%d:%d:%d"`
  = AdapterIndex, OutputIndex, TrimSpace(DeviceName), HDR, ColorSpace, Rotation,
  Bounds.Min.X, Bounds.Min.Y, Bounds.Dx, Bounds.Dy。
- `prepare`（0x1409768e0）：nil cache → `DXGI 输出复制缓存未初始化`(35B)；
  否则 `entryForDisplay(d)` 仅取 error。
- `entryForDisplay`（0x140977020）：nil cache → 同 35B；rotation 0/>4 →
  `不支持的 DXGI 显示器旋转值 %d`(39B)；closed → `DXGI 输出复制缓存已关闭`(32B)；
  lazy makemap；命中返回；否则 `createEntryLocked`。
- `createEntryLocked`（0x140977480）：closed → 32B；`openScreenshotDXGIOutputTarget` →
  `createScreenshotD3D11Device` → `duplicateScreenshotDXGIOutput` → tone-map →
  label → 日志 `DXGI HDR tone mapping: display=%s options=%s`(44B) → 建 entry →
  mapassign → 日志 `DXGI 输出复制对象已缓存: display=%s`(44B)；duplicate 失败先
  `device.release()` 再走 defer `release()`。
- `remove`（0x140977ae0）：nil cache / 空 key → 返回；mapaccess 未命中 →
  解锁返回；expected 非 nil 且不等 → 解锁返回；mapdelete；**解锁后** `entry.release()`。
- `Close`（0x140978780）：nil → 返回；closed → 解锁返回；closed=true；清空 map
  并收集；解锁后逐个 release。
- `Reconcile`（0x140977c40）：wanted 集合跳过 `!AttachedToDesktop || Bounds.Empty()
  || Rotation==0 || Rotation>4`；`now.Sub(lastUsed) > 5*time.Minute` 或不在 wanted
  → 删除收集；`len>8` 时按 lastUsed 升序 `sort.Slice` 裁剪到 8；解锁后统一 release。
- `entry.capture`（0x140978a80）：nil → `DXGI 输出复制缓存项为空`(32B)；
  closed/device/dup 任一空 → `DXGI 输出复制缓存项已关闭`(35B)；lastUsed=Now；
  `captureScreenshotDXGIFrameRegion(device, dup, opts, Rect(0,0,0,0))`；
  **超时哨兵且 lastFrame!=nil 且 !requireFresh** → 日志
  `DXGI 本次无桌面更新，复用上一帧: display=%s`(56B) + `cloneRGBAImage(lastFrame)`；
  其余错误原样返回；成功 `updateLastFrameLocked`。
- `entry.captureRegion`（0x140978ea0）：与 capture 对称；复用日志
  `DXGI 区域捕获本次无桌面更新，复用上一帧: display=%s rect=%v`(76B) +
  `cloneRGBARegion(lastFrame, rect)`；**成功路径不更新 lastFrame**（区域捕获不缓存整帧）。
- `entry.release`（0x140979360）：closed=true；`screenshotCOMRelease(dup)` → dup=nil；
  `device.release()` → device=nil；lastFrame=nil；`lastFrameFree()` → lastFrameFree=nil。
- `entry.updateLastFrameLocked`（0x140979560）：`img==nil || len(img.Pix)==0` → 清空
  lastFrame 并释放预算；否则 `Reserve(int64(len(img.Pix)))`，失败返回；
  `cloneRGBAImage(img)` 替换 lastFrame/lastFrameFree。
- `entry.lastUsedSnapshot`（0x1409796a0）：nil → 零 time.Time；锁内拷贝 lastUsed。
- 缓存重试语义（先修正前批误记）：`cache.capture`（0x140976980）失败时
  **非超时哨兵**才 `remove` + 重建 `entryForDisplay` 重试；超时哨兵直接 `(nil, err)`
  透传（正常"无桌面更新"，由 GDI 兜底）。重建失败
  `DXGI 捕获失败: %v；重建输出复制对象失败: %w`(58B)；区域版
  `DXGI 区域捕获失败: %v；重建输出复制对象失败: %w`(64B)。
- `captureScreenshotDXGIOutputFrameWithOptions`（0x140976020）：未附着/空边界 →
  `DXGI 输出未连接到桌面`(29B)；缓存捕获 → `orientScreenshotDXGIFrame`；尺寸不匹配 →
  `DXGI 旋转后帧尺寸不匹配: frame=%v display=%v rotation=%d`(65B)。
- `captureScreenshotDXGIOutputFrameRegionWithOptions`（0x140976260）：未附着 → 29B；
  rect 空 → `DXGI 输出区域为空`(23B)；`rect.Intersect(Rect(0,0,Dx,Dy)) != rect` →
  `DXGI 输出区域越界: %v`(27B)；纹理矩形换算 → 缓存区域捕获 → orient；尺寸不匹配 →
  `DXGI 旋转后区域尺寸不匹配: frame=%v rect=%v`(53B)。
- `prewarmScreenshotDXGIOutputFrameCache`（0x1409766c0）：`Reconcile(displays)`；
  对附着且非空且 HDR 的显示器 `prepare`，失败
  `DXGI 输出复制对象预热失败: display=%s err=%v`(54B)。
- `cloneRGBAImage`（0x140957320）：nil → nil；`NewRGBA(img.Rect)`；`copy(dst.Pix, img.Pix)`。
- `cloneRGBARegion`（0x1409573a0）：img nil 或 rect 空 → `NewRGBA(0,0,0,0)`；
  `inter=rect∩img.Rect`；`NewRGBA(0,0,inter.Dx,inter.Dy)`；
  `draw.DrawMask(dst, dst.Rect, img, inter.Min, nil, zero, Src)`。
- `screenshotCOMRelease`（0x14097df80）：p/vtable/release 任一零 → 返回；
  否则 `SyscallN(release, p)`。
- `screenshotCOMQueryInterface`（0x14097e000）：p 零或 iid 零 →
  `COM 对象或 IID 为空`(24B)；qi=vtable[0]；`SyscallN(qi, p, iid, &result)`；
  HRESULT 非零 → `%s failed: HRESULT 0x%08X`("COM QueryInterface")；result 零 →
  `COM QueryInterface 结果为空`(31B)。
- 入口 `[S-sig]` 桩签名：`openScreenshotDXGIOutputTarget(
  screenshotDisplayCaptureInfo) (uintptr, uintptr, func(), error)`、
  `duplicateScreenshotDXGIOutput(uintptr, unsafe.Pointer, bool) (unsafe.Pointer, error)`、
  `captureScreenshotDXGIFrameRegion(*screenshotD3D11Device, uintptr,
  screenshotHDRToneMapOptions, image.Rectangle) (*image.RGBA, error)`、
  `screenshotDXGITextureRectForDesktopRect(uint32, int, int, image.Rectangle)
  (image.Rectangle, error)`、`orientScreenshotDXGIFrame(*image.RGBA, uint32)
  (*image.RGBA, error)`（rotation==1 恒等路径已实现，0/>4 报
  `不支持的 DXGI 显示器旋转值 %d`，nil/空帧报 `DXGI 帧为空`(20B)）。
