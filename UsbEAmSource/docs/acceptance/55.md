  释放 factory6 → adapter 空 `DXGI 适配器为空`(20B) → EnumOutputs(adapter,
  d.OutputIndex, &output) → `DXGI 输出为空`(17B) → queryOutput6(output) →
  释放 output；release 闭包释放 output6→adapter→factory1。首返回值是
  **adapter**（非原始 output）。
- `createScreenshotD3D11Device`（0x140979fa0）：levels4={0xb100,0xb000,0xa100,
  0xa000}；哨兵错误则 levels3={0xb000,0xa100,0xa000} 重试。
- `createScreenshotD3D11DeviceWithFeatureLevels`（0x14097a080）：adapter 空
  `D3D11 适配器为空`(21B)；levels 空 `D3D11 feature level 列表为空`(32B)；
  D3D11CreateDevice 10 参；E_INVALIDARG(0x80070057)+levels[0]==0xb100→哨兵；
  HRESULT 非零→`D3D11CreateDevice failed: HRESULT 0x%08X`；device/context 空→
  释放双方 + `D3D11 创建设备结果为空`(30B)。
- `(*screenshotD3D11Device).release`（0x140979425）：nil 安全，先 context 后 device。
- `duplicateScreenshotDXGIOutput`（0x14097a520）：hdr 先 [0xa]，成功日志
  `DXGI 输出复制优先使用 FP16 格式`；失败日志 `DXGI FP16-only 输出复制失败，
  降级尝试兼容格式列表: %v`；最终 [0xa,0x57]。
- `duplicateScreenshotDXGIOutputWithFormats`（0x14097a660）：nil/空校验；
  DuplicateOutput1@0xd0 六参；HRESULT→`IDXGIOutput5.DuplicateOutput1 failed:
  HRESULT 0x%08X`；空→`DXGI 输出复制对象为空`；成功日志 `DXGI 输出复制格式列表: %s`。
- `captureScreenshotDXGIFrameRegion`（0x14097a920）：3 次重试；超时哨兵或近黑帧
  共用日志 `DXGI 捕获疑似黑帧，准备重试: attempt=%d/%d`（0x140c8a2dc 去重）；
  3 次耗尽→`errScreenshotDXGICaptureFrameTimeout`。
- `captureScreenshotDXGIFrameRegionOnce`（0x14097ac40）：AcquireNextFrame@0x40
  3×100ms 循环；0x887a0027 重试；resource 空→超时哨兵；defer ReleaseFrame@0x70、
  release(resource)、release(texture=QI IID_ID3D11Texture2D)、release(staging)、
  Unmap@0x78；GetDesc@0x50 → 空 `DXGI 捕获纹理为空`(23B)；resolveCopyBounds；
  日志 `DXGI 捕获纹理: size=%dx%d format=%s ...`；staging Usage=3 CPUAccess=0x20000；
  CreateTexture2D@0x28；整帧 CopyResource@0x178、否则 CopySubresourceRegion@0x170
  (box{front=0,back=1})；Map@0x70；近黑→超时哨兵；否则 mappedTextureToRGBAWithToneMap。
- 像素拷贝：0xa→copyRGBAFloat16（SDR 快路径 + 逐像素 tone-map）、0x57/0x5b→BGRA
  swapAlpha=true、0x58/0x5d→BGRA swapAlpha=false、其余→`暂不支持的 DXGI 截图格式: %s`。
- 近黑判定：R/G/B≤3（float/byte），`sampled*995 <= dark*1000`。
- float16→float32 LUT：65536 项 subnormal 归一化 + exp 偏移 112。
- sRGB LUT：4097 项，`x=i/4096.0`，linear→sRGB，round(x*255) 夹 [0,255]。
- tone-map：m=1.0 恒成立；peak=max(maxInput/sdrWhite,1.001)；
  refWhite=clamp(0.5*(1/peak²+1),0.001,1.0)；B=1/m；A=sdrWhiteOutput/refWhite；
  per-pixel `q=peakRGB/sdrWhite; mapped=q*(q/peak²+1)/(q+1); scale=A*B*mapped
  夹[0,1]; scale/=peakRGB`。
- `screenshotHDRToneMapOptionsForDisplayWithSDRWhiteResolver`（0x1409ad8e0）：
  !HDR→1.0；resolver nil/失败/低于下限(2.5374999)→2.5374999；maxInput=
  maxLum≤80?8:clamp(maxLum/80,2,16)；sdrWhiteOutput=0.55；rolloff=1.35；
  env 覆盖 `USBEAM_SCREENSHOT_HDR_SDR_WHITE_LEVEL`/`_OUTPUT`；最终共享 clamp。
- `formatScreenshotHDRToneMapOptionsForDebug`（0x1409ad660）：clamp 后格式
  `sdrWhiteLevel=%.3f sdrWhiteOutput=%.3f maxInputLevel=%.3f highlightRolloff=%.3f
  referenceWhiteOutput=%.3f`。
- `screenshotDXGITextureRectForDesktopRect`（0x14099e920）：Canon + 桌面越界校验；
  rotation 2/3/4 映射（tw=dx/th=dy，rotation 2 用 dx 作纹理高）；纹理越界校验。
- `orientScreenshotDXGIFrame`（0x14099ee00）：nil/空→**`DXGI 捕获帧为空`(20B)**；
  1 恒等；2 顺90/3 180/4 逆90 逐像素重排（uint32 拷贝）。
- `queryScreenshotDisplayConfigSDRWhiteLevelForDisplay`（0x140975000）：
  sdrWhite=raw/1000，nits=sdrWhite×80（仅日志）；raw==0 或 sdrWhite≤0/NaN →
  `忽略无效` + `(0,false)`。
- DisplayConfig 解析链（死代码）：user32.dll 三入口 + Type=1(源名)/Type=11(SDR 白点)；
  ERROR_INSUFFICIENT_BUFFER(122) 重试 4 次。
