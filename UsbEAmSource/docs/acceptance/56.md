## G3 逻辑等价

关键实证（asm VA → Go，均为签名 + 体双重修正）：

- `loadUnlocked`（0x140894fa0, 108L）：真实签名 **4 值**
  `(int, map[string]launcherConfigIconRecord, *launcherConfigIconStoreBudget, error)`。
  成功路径 rax=[s+0x38]=cached.Version、rbx=副本 map、rcx=newobject(24B budget 快照)、
  rdi/rsi=0；错误路径 rax=1、rbx=makemap_small 空 map、rcx=0。体：ensureLoadedUnlocked
  → makemap(hint=len(cached.Icons)) + mapiter 逐项拷贝 Icons + newobject 快照
  cachedBudget 三字段（0x48 count / 0x50 decodedBytes / 0x58 pixels）。3 处调用点
  （Put/externalize/Prune）改 4 值接收。
- `writeUnlocked`（0x140895a80, 47L）：真实签名
  `(lib launcherConfigIconLibrary) error`，非无参方法。morestack 存 3 寄存器
  （s, lib.Version, lib.Icons）；错误消息 `.rdata` 解码 = `图标库路径不能为空`(27B)。
  体：validate(lib)→(budget,err) → writeLibrary（nil 回退 writeLauncherConfigIconLibraryFile）
  → 成功后 s.cached=lib、s.cachedBudget=*budget、loaded=true、cachedLoadErr=nil。
  3 处调用点改 `writeUnlocked(s.cached)`。
- `validateLauncherConfigIconLibrary`（0x140895e80, 39L）：真实签名
  `(*launcherConfigIconStoreBudget, error)`，非单值 error。返回布局
  (rax=budget 指针, rbx=error.itab, rcx=error.data)。体：Version!=1 → count>8192 →
  sort.Strings(refs) → 逐项 normalize 一致性 / ContentType TrimSpace+ToLower 一致 /
  Data TrimSpace 非空 / budget.add(`icons[<ref>(`, `data:<ct>;base64,<data>`) /
  newRef==ref。拼接常量 `.rdata` 解码：`icons[`(6B) `(`(1B) `data:`(5B) `;base64,`(8B)。
