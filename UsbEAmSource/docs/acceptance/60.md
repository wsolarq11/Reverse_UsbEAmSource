## G4 阻断残留（诚实标注）

- 新增依赖 `golang.org/x/net v0.56.0`（`go get`，与目标 exe buildinfo 的 dep 版本一致：
  h1:Rw8j/hFzGvJUZwNBXnAtf5sVDVt+65SK2C7IxCxZt5o=）。go.mod/go.sum 已更新。
- 已知偏差：`extractBookmarkPageTitle` 汇编对 tokenizer 内部字段 `MaxBuf@+0x60` 置 0x80000
  （512KB），该字段非导出，无法从 Go 侧设置，已注释说明（默认 2MB，功能一致，仅缓冲上限放宽）。
- 已知偏差：`fetchBookmarkPageTitle` 第二参汇编为 `0x12a05f200`（5e9 ns = 5s，timeout 语义），
  现有 `LauncherNetworkAccess.Do(*http.Request, int64)` 形参命名 `maxBytes` 系旧批误标，
  本批按 `int64(5*time.Second)` 传递（ABI 同为 int64）；语义校正归 network 域专项。
- 已知偏差：`extractBookmarkPageTitle` 汇编直接读 tokenizer 内部 `z.err` 字段做
  `errors.Is(err, io.EOF)`，Go 侧以 `tz.Err()` 公开 API 近似（Err() 已把 io.EOF 归 nil），
  语义等价，字节级布局不逐位对齐。
