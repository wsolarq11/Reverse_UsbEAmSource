## G3 逻辑等价（asm 实证）

- `launcherConfigOptions@0x140775660`（64B）：真签名 `(bs, locale string) LauncherConfigOptions`。
  asm 入口 `rbx=locale.ptr, rcx=locale.len` → languageDirectories → loadLanguageMessages →
  `defaultTagCatalogFromLanguageMessages(msgs, locale)`。旧重建树误为无参形式，本批补参。
  调用点实证：loadLinkPreferences 传硬编码 "en-US"（`lea rbx,[rip+0x4cbf04]` → 0x140c35be6 = "en-US"）；
  SaveConfig/CompleteInitialization/commitConfig 均从调用者栈槽取 cfg 的 Language 字段（非 rip 常量），
  故按 `cfg.Preferences.Language` 传递。
- `defaultTagCatalogFromLanguageMessages@0x1407756c0`（448B）：真签名 `(langMsgs, lang string)`。
  完整 asm 实证体：先 `mapaccess2_faststr(langMsgs,"en-US")` 命中则 `mergeLanguageMessages(&merged,val)`；
  `TrimSpace(lang)` 空则 fallback "en-US"（magic 0x552d6e65="en-U"+0x53='S' 判等）；
  `lang != "en-US"` 则二次 mapaccess 命中再 merge；
  `nestedLanguageMessageString(&merged,"tags.defaults")` → splitTagText → defaultTagCatalogFromNames。
  旧实现（无 lang 参 + 早期 len 守卫 + 扁平回退）被完整替换。
