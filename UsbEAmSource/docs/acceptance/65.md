## G4 本批校正（诚实标注）

**`LaunchAppWithPrivilege@0x1408a60c0`（512B）签名证伪**：第二形参实非 `int flags`（int 走寄存器 rdi，
而 asm 第二形参走栈槽 [rsp+0x458]+[rsp+0x460] 经 duffcopy，系 AppEntry 结构/单元素切片）。
asm 体：`normalizeAppEntries([]AppEntry{entry}, 1)` → 空则 error → `normalizeAppLaunchPrivilegeMode(appID)`
（magic `0x61666564`+"ul"+"t" = "default" 判等）→ ""/"default" 则 `loadAppLaunchPrivilegeDefault` +
`resolveEffectiveAppLaunchPrivilege` → `startApplication(normalized[0], privilege)`。
调用点 bootstrapservice.go:1523 传 `7` 亦需同步校正。保持 [P]，签名校正与 app 启动域合并专项。
